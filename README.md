# 🦌 Otak Kancil

**Otak Kancil** adalah aplikasi edukasi Android yang membantu pengguna belajar dan mengasah pengetahuan melalui materi, kuis, dan progres belajar.

> Belajar sedikit demi sedikit, berpikir lebih tajam setiap hari.

## ✨ Fitur

- 📚 **Materi edukasi** — pelajari materi berdasarkan kategori.
- 🧠 **Kuis interaktif** — uji pemahaman setelah belajar.
- ⭐ **XP dan level** — kumpulkan XP dan tingkatkan level.
- 📈 **Progres belajar** — pantau perkembangan belajar.
- 🎯 **Misi harian** — tantangan untuk membangun kebiasaan belajar.

> Catatan: pastikan fitur-fitur di atas sudah tersedia pada versi yang dirilis. Hapus atau ubah fitur yang masih dalam pengembangan.

## 📖 Fokus Pembelajaran

Otak Kancil berfokus pada materi yang bermanfaat untuk pelajar dan pembelajar umum, seperti:

- Sains
- Teknologi
- Logika
- Pengetahuan umum
- Biner dan komputasi

Kategori serta ketersediaan materi dapat berubah seiring pembaruan aplikasi.

## 📲 Unduh Aplikasi

Unduh APK dari halaman **Releases** repository ini:

**[Unduh Otak Kancil versi terbaru](../../releases/latest)**

1. Buka halaman rilis terbaru.
2. Unduh file APK yang tersedia.
3. Buka file APK di perangkat Android dan ikuti petunjuk instalasi.

Android mungkin meminta izin untuk memasang aplikasi dari sumber yang dipilih. Pastikan file berasal dari rilis resmi repository ini.

Menemukan bug atau punya ide fitur baru?

1. Buka tab **Issues** pada repository ini.
